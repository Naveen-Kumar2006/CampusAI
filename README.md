# 🎓 CampusAI

CampusAI is an AI-powered college assistant that uses **RAG (Retrieval-Augmented Generation)** to answer student queries from uploaded college documents.

## 🚀 Features

- 🤖 AI-powered college chatbot
- 📚 PDF document-based Q&A
- 🔎 FAISS vector search
- 🧠 Gemini LLM
- ⚡ FastAPI backend
- 🌐 Dummy college website integration

## 🛠️ Tech Stack

Python • FastAPI • LangChain • FAISS • Ollama • Gemini

## 🔄 Workflow

```text
Student Question
       ↓
Dummy College Website
       ↓
FastAPI
       ↓
RAG + FAISS
       ↓
Gemini
       ↓
Answer

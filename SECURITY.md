# Security Policy

## Supported Versions

CampusAI is currently under active development. Security updates will primarily be provided for the latest version available on the main branch.

| Version | Supported |
|---|---|
| Latest (main branch) | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in CampusAI, please report it responsibly.

**How to report:**
- Use GitHub's Private Vulnerability Reporting feature through the repository's Security tab.
- Provide a clear description of the vulnerability.
- Include steps to reproduce the issue, if possible.
- Include screenshots or proof of concept when applicable.

**What to expect:**
- Vulnerability reports will be reviewed as soon as possible.
- You may receive requests for additional information.
- Confirmed vulnerabilities will be investigated and addressed.
- Security fixes will be included in an appropriate update.

Please avoid publicly disclosing security vulnerabilities before they have been investigated and addressed.

Thank you for helping keep CampusAI secure!
